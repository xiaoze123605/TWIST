# heading_300：第一阶段诊断、根因排序与最小修改方案

基线：TWIST仓库分支`recovery/motion-wm-opentrack-4900`，提交`5e45fe8`。本轮只增加可选只读诊断、运行独立控制消融和无学习采样审计；没有修改网络、训练奖励或原模型，没有启动短训或长训。用户其他OptiTrack改动保留。第二、三阶段以下均为待验证方案，不宣称已实现训练改善。

## 结论

77的明显蹲姿问题主要表现为膝、髋、踝协调偏差和蹲深不足；记录不支持“机器人持续比参考更加前倾”这个解释。参考本身包含明显躯干前倾。行走高频波动在heading修正之前已经存在，踝Pitch最突出，且动作突变集中于接触切换。关闭heading头没有降低抖动，朝向明显退化。深蹲专项学习覆盖和奖励平均量级较低，适合先单独改善采样。尚未证明COM越出支撑区是主因，也没有腿/腰力矩饱和证据；不要直接强制躯干直立、提高PD或取消投影。

目前没有任何新设置通过全部验收。保留heading_300为本轮基线，原23500为对照；不以EMA消融替换模型。

## 记录与方法

每帧保留23关节clean/processed参考、实际角/速度、25关节原始/投影后PD目标及裁剪差、EMA前策略输出、EMA后动作和23关节变化率；额外记录骨盆RPY、躯干Pitch、足部位置/地面接触力、COM、COP、足接触凸包及静态支撑裕量。关节名字和23/25映射写入首帧schema。

每个动作区间另外聚合全部20个1 ms物理子步的请求力矩峰值/RMS、控制器裁剪后力矩RMS和饱和比例。状态位于动作开始，力矩统计属于随后20 ms，不混用上一帧执行结果。饱和定义是请求力矩达到现有PD控制器限值；不是电机电流/温度测量。

参考COM和躯干通过相同XML重建，参考根部XY锚在实际根部，只比较足相对姿态；这是运动学参考，不证明运动物理可实现。实际COM/接触使用MuJoCo现有动力学缓存，其刚体几何与qpos可能有一个1 ms积分步的偏差。接触凸包是静态指标，不能单独判定动态步行稳定性。

片段条件：深蹲为clean高度<0.7 m且双膝平均>0.8 rad，共4.74秒；下降/起身为高度<0.78 m、双膝平均>0.5 rad且平滑高度速度分别<-0.03/>0.03 m/s，共3.30/3.08秒；行走为高度>0.74 m且参考水平速度>0.15 m/s，共42.40秒。这些条件可以重叠，不把各占比直接相加。深蹲分散在约5.66–11.50和43.98–49.80秒，完整区间列表在JSON中。

频域使用50 Hz记录、连续片段至少1.28秒、64点Welch、线性去趋势、5–20 Hz积分，避免拼接不连续片段制造假频率；有效行走频谱长度36.84秒，分辨率0.78125 Hz。高频分量不是自动等同于有害动作，必须结合参考、接触与跟踪代价。摔倒后的信号不用于频谱比较。

## 下蹲、起身与前倾

WM深蹲躯干Pitch平均：参考16.73°、WM参考16.26°、实际11.86°；参考相对实际误差RMSE5.92°，实际减参考的P95仅+0.28°。下降阶段参考12.88°、实际7.58°；起身参考14.90°、实际11.32°。不支持对所有下蹲状态新增“Pitch→0”的惩罚。若目标是比77原姿态更直立，应先单独验证参考姿态调整能否同时保持足、手位置和COM约束。

深蹲COM相对双脚中点的前向偏移：实际1.76 cm、参考4.55 cm，实际更靠后2.79 cm，而非明显向前失控。89.87%深蹲帧双脚地面竖向力均>5 N；在可信双接触、接触凸包有效的帧中，静态COM裕量平均5.02 cm，8.49%为负，下降时负裕量15%。支撑瞬态仍值得优化，但这不等于已证实全程平衡失效。

关闭投影：深蹲Pitch RMSE5.90°，几乎不变，而全长yaw从32.08°退化到77.10°。深蹲41%的帧至少一个关节被投影，主要是右踝Roll，髋Pitch和膝没有被裁剪。投影是局部踝行为因素，不是膝欠弯的直接根因；不推荐全局取消它。

表内EMA数值为全量动作的已有runtime参数，不是只平滑AnyAdapter残差。EMA反馈也进入last_action和79帧历史，因此是闭环消融，不只是对同一条离线曲线滤波。EMA0.25令实际高频RMS下降8.23%、变化率下降9.59%，但速度误差增加约8.8%；EMA0.5即使策略输出高频显著下降，实际高频几乎不变且速度退化。没有一个EMA设置通过建议的+5%逐动作速度保护。EMA延迟的低频近似为alpha/(1-alpha)×20 ms，0.25/0.5/0.75约6.7/20/60 ms，不能盲目增大。

原参考行走高频腿角RMS0.00435 rad，实际0.00917 rad，策略EMA前动作0.04500 action单位；这确认高频并非仅来自原参考。踝Pitch实际高频最明显，左/右0.01561/0.01407 rad，PD目标0.03852/0.03541 rad；髋Roll目标也较高。主高频峰在5.47 Hz附近，接近分析带下边界，不能据此声称存在单一5.47 Hz自激模态。

足接触切换±40 ms内，腿动作变化率RMS6.17，远离切换2.83，约2.18倍；说明接触反馈/落脚平衡补偿是重点检查方向。现有训练和部署都将踝速度观测置零，可能限制踝反馈，但未经独立消融，不能认定它是主因，更不能仅改部署观测。

heading头：行走下肢修正RMS仅0.000390 action单位，高频0.0000205；总输出高频0.0450。关闭头后实际高频反而增加约6.1%，yaw近乎翻倍。朝向改善来自小修正在闭环中累积，必须保留它。现有数据不能把抖动归因于新heading头，也尚未把冻结TWIST与核心Adapter的贡献完全分离；应优先针对策略已有的闭环高频，而非更换网络。

回放为128环境×512步，65536环境帧，每环境10.24秒、81次重置、seed42；加载原manifest和固定model_300，在训练的随机化/噪声条件下执行确定性均值策略。优化器步数0。不是原300更新的历史PPO采样日志，也不代表完整长期分布；原训练未记录上述逐状态覆盖，不能倒推精确历史值。

77不在该训练YAML中，应继续作为回归动作，不把它单独高权重加入训练后仍称为泛化验证。审计按姿态识别蹲起，未仅凭文件名选样本。

回放中深蹲膝专项奖励平均贡献仅-0.000103/环境步，heading约-0.002776，量级约27倍；有效深蹲时平均膝绝对误差约0.254 rad。说明膝奖励不是完全无信号，但被少量有效状态稀释。奖励量级不等于梯度量级，不能据此直接把膝系数提高27倍。先改采样，保留现有权重，独立验证。

## critic适配与续训隐患

实际审计actor输入7003、critic1318。critic仍使用旧的未来参考、proprio和priv_info，没有追加2维heading context；未来参考包含参考yaw，proprio包含roll/pitch和角速度，并非实际yaw。local-root下实际keybody位置与根速度也不能直接提供世界绝对heading。因此存在对heading误差不同但critic输入相同的状态给出同值估计的风险。当前仅确定输入结构缺失，未证明这是蹲姿或抖动的直接原因；先保留critic结构，记录按yaw误差分组的价值残差，再决定是否需要训练专用的小适配。

特别注意：`train_23500_heading.py`当前教师target只调用`source.layerwise_actor(...)`，而学生mu包含`heading_delta(...)`。当原始23500为source时，新增头为零，这不会遗漏已有修正；换成已学习的heading300为source时，却会遗漏其heading修正。第三阶段新分支前必须把冻结教师的完整动作（core+heading_delta）作为锚定目标，并测试同一观测下初始化学生与教师完全一致。`train_23500_plane.py`已有这种处理，但它还混合baseline教师和新平面奖励，不能直接当作本轮单因素数据实验。

## 根因优先级

1. **高置信：参考前倾与实际蹲姿协调误差需要分开处理。** 参考自身前倾，膝欠弯、髋/踝偏差和目标方向一致，腿腰未饱和，关闭投影不能修复。优先实际蹲深/髋膝踝协调，避免全局直立惩罚。
2. **高置信的学习瓶颈，因果仍待短训：支撑深蹲样本少、专项信号平均量级弱。** 有效覆盖仅约2.5%，适合先单独改采样分布；不能声称增加采样必然解决。
3. **中高置信：已有策略/接触闭环输出高频，踝Pitch最突出。** EMA前存在额外高频，接触切换附近动作变化大，heading头消融不改善。尚未完全拆分TWIST、核心Adapter、接触反馈和观测噪声；PD物理高频及稳定性不能靠EMA输出曲线独立判定。
4. **中置信：右踝Roll投影和短暂支撑裕量不足是局部因素。** 不能解释未裁剪膝的系统偏差；采用局部可行域/实际支撑检查，不取消全身投影。
5. **确定的结构风险，直接因果未证实：critic缺heading与新source教师遗漏heading。** 后者必须在启动新分支前修正，前者单独记录/消融，不先改actor结构。
6. **不支持为主因：heading头导致腿抖、膝力矩饱和、单纯启动不同步。** 对应独立检查没有支持。

## 最小修改方案与分阶段门槛（未启动训练）

**P0：必要兼容修复。** 仅修正新source教师为完整heading300动作，初始化/导出/教师数值对齐。冻结TWIST、历史编码器、Motion-WM不变，所有23关节仍共同控制，当前头不关闭；另建目录，不能绕过旧resume签名。

**A：只改采样。** 从审计清单选择训练集中可行的深蹲/起身片段，增加带相邻上下文的片段采样，不截断成静止姿态。先试有效深蹲约10–12%、可信支撑深蹲约5–8%，保留至少75–80%原分布和raw/wm比例0.5/0.5、转向覆盖。下降/起身已有8–9%有效占比，不一起无限增权。奖励、增益、投影、EMA和网络全保持不变；预算250更新，每50更新评价live，必要时评EMA权重，允许曲折改善。

**B：只加一个参考相对支撑约束，作为独立分支。** 在双支撑可信、参考低速的蹲起状态约束COM相对支撑的偏移或支撑裕量不足，并设死区；跟踪参考允许的倾斜，不以Pitch=0为目标，不误罚摆腿或正常迈步。先由离线运动学/短仿真验证参考的手、脚、COM可兼顾。若确实要求更直立的77风格，先独立验证小幅参考姿态修正，不能只把参考Pitch清零。B不要一开始和A、多项新奖励混合。

**C：策略输出平滑独立分支。** 已确认EMA前高频存在，可在A/B之外单独比较更小EMA(例如0.1/0.15)或弱的动作二阶差分训练项；优先只惩罚超过正常参考/转向变化的高频，不抑制有效朝向和摆动。一次只试一项，模型执行历史语义与训练一致。当前0.25/0.5/0.75结果不足以直接采用。踝速度观测恢复、PD变化均需新独立消融和一致训练，暂不实施。

**D：critic仅在价值残差证据支持时单独适配。** 如果heading误差分组残差明显，训练critic追加2维sin/cos通道、原权重保留、新列零初始化，actor/JIT结构不变。这是很小的训练侧变更，但当前阶段先不动；不能和A/B/C捆绑后失去归因。

**第三阶段组合规则。** 分别证明A/B/C改善对应指标且守住yaw/速度保护后，再从heading300的完整checkpoint新开组合分支，保持独立优化器和短价值预热，预算250–500更新，每50–100更新评估。原23500和heading300永久保留对照；最终用未调参的蹲起、行走、转向及其他长动作和seed43确认。仅表现最佳checkpoint进入下一阶段，不要求奖励或各次保存单调改善。

**建议量化验收：** 参考相对躯干Pitch误差、蹲深与髋膝踝误差改善，不能通过牺牲参考意图换低绝对Pitch；行走5–20Hz实际腿角RMS与加速度下降至少10%；各raw/wm的yaw RMSE不高于heading300约5%（77 WM约33.7°），同时逐动作速度退化不超过5%、无新增失稳。比例与绝对误差都看，当前指标只是单seed诊断，尚无方案通过完整验收。
