## 3. 核心机制（transanchor_norm 设计，在 `tools/train_4900_improved.py`）

- 冻结 TWIST base + AnyAdapter 残差（zero-init）微调，PPO4900Improved 类。
- **过渡感知锚定**：每样本权重 `w = 1 + 9·max((|v−EMA|/0.4)², (|yaw|/1.5)²)`（上限 10），EMA=参考速度 1s 滤波沿每个 env 轨迹时序推进（episode 重置由 11 帧相同历史检测并重启 EMA）。
- **关键：w 每 update 按批均值归一化**，使平均锚定压力 == base 调度（0.3→0.1/500 updates）。自由帧有效锚 ≈0.09（有增益空间），过渡帧 ≈0.78（钉住 source，防尾巴回归）。这是 @100 通过的核心改动；无归一化的版本（transanchor_seed42_20260925，已弃）会把 adapter 钉死（@50 score 1.0126）。
- 其他：replay bank 16384 + bank_w 权重持久化；adapter EMA 0.99 快照；cosine LR 2e-6→2e-7/20000；std anneal；mode probs (.5,0,.5)；prefill_history=True。
- 校准工具：`tools/probe_ref_speed.py`（离线，无模拟器，读 train.yaml MotionLib 统计）。
