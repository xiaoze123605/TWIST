# heading300短时闭环敏感性与状态覆盖诊断（2026-10-13）

**结论：本轮实际访问状态上没有动作偏差越过1e-4的证据；完整动作77仍出现明显WM Yaw退化。短时分叉说明小扰动可以通过接触/动力学及状态历史留下持续影响，但5秒局部测试不能预测整段64.14秒表现。heading300继续作为唯一最优参考，本轮结束后停止，不训练、不更改阈值。**

诊断阈值预先固定：关节最大差>1e-3rad、足部垂直力差>50N；支撑标签沿用>5N；Yaw超过1/5/10°需持续10周期=0.2秒。它们是描述性事件阈值，不是新增训练奖励或唯一因果起点。

clean/processed参考在两策略间逐帧完全一致；WM输入历史及ready标志也相同。历史的(s_t,a_t)→t+1配对检查全部为0误差，排除已记录的错帧。Motion-WM在这里由外部参考历史驱动，并非由机器人状态反馈改写参考。raw/WM自身参考不同可改变路径敏感性，当前不能推断WM结构存在缺陷。

## 7. 情形判断与证据强弱排序

1. **最强：情况A未被观察到，幅值约束并不足以保护完整闭环。**新策略实际访问状态和全部分叉均未越界，但WM完整轨迹显著退化。不能继续以扩大anchor池或压低平均MAE作为已被证实的解决方案。
2. **强：小策略变化经物理—状态/动作历史反馈可产生持续轨迹影响。**所有null精确，C/D仅改变有限周期策略即可留下接触/关节/Yaw差异，支持情况B的机制方向；5秒分叉的Yaw幅度只到约1.66°，不夸大成短时复现77.93°RMSE。
3. **中等：前缀演化和持续作用有显著路径依赖。**完整从0秒与12秒重新从baseline起点的结果明显不同；WM8秒的B/C/D支持局部持续效应。状态与历史尚未独立拆分。情况C局部成立、非普遍规律。
4. **较弱/尚未证明：具体摩擦、某个关节、某次碰撞或heading头是唯一根因。**没有单关节/接触因果干预；不能从事件先后或力差大小直接得出唯一机制。

raw同样有接触/历史放大，但最终Yaw误差改善；WM最终恶化。当前证据支持不同参考路径下非线性闭环净结果不同，不支持“只有WM发生状态错位/反馈修改参考”。

## 8. 唯一下一步方向及作用边界

**推荐将下一轮候选Actor更新的接受依据升级为完整双模式闭环轨迹保护门，并在失败时联合恢复Actor参数和对应Adam状态。**原1e-4检查可保留为局部功能约束，但不能独立判定模型安全，也不能用5秒fork代替64.14秒完整验收。最小后续对照只增加这一个轨迹接受/回退条件：固定原参考、seed、raw/WM及控制条件；WM Yaw≤33.68°、raw≤71.17°，同模式根速度≤基线105%，无新增跌倒；接受的候选还必须证明非零Actor更新。失败候选不得成为后续Actor优化起点。

这是针对本次证据最直接的性能保护方法，不是已经实现或验证的训练改进。它不能直接消除下蹲误差和行走抖动：作用是防止后续优化这些目标时破坏原有朝向能力。也不保证一定能接受有益更新；若全部候选被拒绝，应报告无有效学习，不能宣布解决。现阶段证据不足以选定新的PD/EMA/摩擦/奖励改法。

本轮只推荐这一方向，不执行新训练、不调整阈值、不新增控制器。后续必须另行授权，并先证明回退涵盖Actor及Adam状态，独立结果不覆盖原checkpoint。
