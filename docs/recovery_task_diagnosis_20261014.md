# 真实参考、初始化与控制权限诊断：2026-10-14

本阶段按约定没有训练、没有修改原控制模型或部署路径。完成原运动参考核对、连续物理预滚动、初始偏差回放、相同闭环状态分叉、有限关节修正、外力矩扰动和逐项奖励检查。正式结论只来自 `reports/recovery_task_diagnosis_20261014_final/`。

## 1. 参考语义与任务内容

原文件为 `track_dataset/twist_motion_dataset/mocap1/77.pkl`，3210 帧、50Hz、23DoF。与 MuJoCo 的25DoF映射明确：两个 wrist roll 在原高层程序中插零，源文件没有这些通道。本轮沿用这一既有定义，没有从实际动作反推参考。

用原 MotionLib 与 `build_mimic_obs` 重建 trace1950–2500 的参考。在原策略实际消费的 float32 精度下，31维参考与历史记录逐元素相同。原高层配置 `--steps 1` 表示参考提前20ms；控制帧2100–2499消费的源运动时刻是42.02–50.00秒。

原 loader 的速度定义是原运动位置/四元数前向差分、19样本居中平滑后再转机体系。根位置与显示姿态都需移除初始heading，线速度比较也必须使用同一坐标。修正诊断坐标后，参考世界速度与未平滑位置差分的RMSE为0.04634m/s。参考角速度是body angular Z，而非欧拉yaw导数；转换后与未平滑yaw差分的RMSE为0.11852rad/s，转换前为0.12377rad/s。这些比较包含平滑和插值定义差异，不能认定残差即为时序错误。

原高层的20ms前瞻还意味着，原奖励“执行后状态对本次指令参考”的时间关系不能仅凭读取顺序就认定错一帧。本轮保存了再提前一帧参考的反事实回报，但没有把它当作修正版本，也未改奖励。

候选片段并非简单的慢速转向再保持：

- 8秒净转向−89.11°，其中前1.5秒变化约−91.81°，之后有小幅回转。
- 参考body angular Z峰值约2.415rad/s，yaw数值导数峰值约2.656rad/s（152.2°/s）。平均11.14°/s不能代表主要转向阶段的难度。
- 转向后包含连续深蹲，root height约0.525–0.808m，最大pitch约0.517rad。
- 没有参考关节超出XML硬限位；69帧左膝、89帧右膝低于投影后的目标下限，合计占所有关节样本的1.58%。该统计是软目标约束，不能写成硬关节不可达。
- 参考FK足底球最低高度约左+2.26mm、右−5.67mm，无帧出现超过2cm的足底穿地。接触依据足底高度仅是启发式，未证明参考接触动力学可行。
- 最大参考关节差分速度4.536rad/s；阻尼项单独未超过力矩上限，不构成完整执行器可达性认证。

## 2. 初始化对照：旧策略本身存在显著状态依赖

连续运行0–50秒时，2500帧qpos、qvel、RPY、关节、动作及PD目标与已保存原基线最大差均为0。

参考状态初始化使用源运动39.00秒的姿态、根位置、速度和关节速度，下一指令为39.02秒。坐标与原高层一致；策略历史从空开始，通过3秒真实物理执行填充，而非仅灌入参考。这与连续42秒闭环历史是不同的初始化条件。

| heading300初始化条件 | 42–50秒yaw RMSE | joint RMSE | 最低高度 | 跌倒代理 |
|---|---:|---:|---:|---|
| 原运动0秒开始连续执行至42秒 | 98.1799° | 0.139132rad | 0.5315m | 无 |
| 默认站姿直接执行42秒参考（反例） | 57.2034° | 0.142975rad | 0.5375m | 无 |
| 39秒参考状态初始化＋3秒物理预滚动 | 9.4195° | 0.140189rad | 0.5326m | 无 |
| 0秒初始yaw−10°，连续执行 | 105.6812° | 0.139208rad | 0.5316m | 无 |
| 0秒初始yaw+10°，连续执行 | 93.6924° | 0.139348rad | 0.5239m | 无 |

这是同一旧策略在不同进入条件下的比较，**不是新策略收益，也不是只改变单一物理变量的因果实验**。参考状态初始化同时改变位置、速度、姿态、接触演化和历史，因此不能归结为单一yaw初始化错误。它支持此前积累的误差会掩盖局部任务能力；也表明不能直接判定该片段整体不可执行。

初始±10°实验的统计窗口只有42–50秒，不据此估计0秒扰动的完整恢复时间。绝对参考误差与配对轨迹偏差均保留。

## 3. 完整闭环分叉与36次受控动作探测

保存MuJoCo积分状态、warmstart、传感器缓存、策略历史、物理历史、上一动作、参考/速度缓存、观测缓存和RNG。在两种合理进入条件的42、45、48秒分别分叉。每个点的零干预分支都与其独立连续轨迹逐元素一致。

预声明的动作集合只有三种组合：双髋yaw同向、双髋yaw反向、双髋roll与双踝roll配合；每种测试正负方向。动作修正幅度0.03，对应直接PD目标0.015rad，持续0.2秒，观察0.5秒。两种进入条件×三个点×三组合×两方向，共36次，未根据结果扩大范围或调参。

实测：

- 首个控制周期的PD目标变化与预定0.015rad映射最大差1.43e-8rad；没有被投影或裁剪整体抵消。
- 每种进入条件18次中9次减少短时绝对yaw IAE、9次增加。
- 36/36次中，yaw IAE改善/恶化与综合回报增加/减少的方向一致；本组未发现纠偏被综合奖励反向惩罚。
- 所有0.5秒探测未出现跌倒代理。它不代表长时稳定，倾角、关节和接触变化仍保存在轨迹。
- 局部初始化下，反向双髋yaw的有效符号在42、45、48秒不同；不能用一个固定偏置代替状态条件化的恢复策略。
- 三个探测点均为双脚接触。400帧局部轨迹中365帧双脚接触、33帧仅右脚、2帧仅左脚；本次没有覆盖足够单脚支撑探测，不能外推到行走步态。

表内短时PD变化的后续最大值可大于0.015rad，因为源策略会在变化后的状态和历史上继续响应；这与首周期直接执行映射是不同量。

![奖励敏感性](../reports/recovery_task_diagnosis_20261014_final/reward_sensitivity.png)

这些结果支持“当前动作空间存在若干短时有效方向、当前奖励可以识别”，不能证明最优动作可达、PPO探索充分或恢复教师会收敛。短时改善方向来自有限人工探测，不应被直接当作最优教师标签。

## 4. 外力矩扰动：早期返回不等于持续恢复

在42秒给pelvis施加世界Z方向±1Nm外力矩，持续0.2秒。分别与同一进入条件的无扰动旧策略轨迹配对，观察8秒。

| 进入条件 | 外力矩 | 最大额外yaw | 首次≤2°保持1秒 | 此后再次超界 | 末1秒额外yaw RMS |
|---|---:|---:|---:|---|---:|
| 连续0–42秒 | −1Nm | 2.585° | 0.20秒 | 是 | 2.435° |
| 连续0–42秒 | +1Nm | 2.099° | 0.42秒 | 否 | 0.391° |
| 参考39秒＋物理预滚动 | −1Nm | 11.078° | 0.20秒 | 是 | 10.454° |
| 参考39秒＋物理预滚动 | +1Nm | 7.196° | 0.20秒 | 是 | 6.767° |

早期保持1秒这一局部门槛可以在误差尚未发展时满足，所以必须同时报告再次超界、全窗口IAE、末段误差和绝对参考误差。不能凭0.2秒恢复时间宣布有鲁棒恢复能力。若下一阶段使用“成功恢复”标签，应事前固定扰动结束后的监测窗口，并要求尾段持续恢复；指标不能事后为某个策略放宽。

## 5. 下一轮应如何收敛

本阶段达到的是诊断完成，不是新模型验收通过。参考39秒＋真实预滚动能提供较好的名义航向跟踪，但仍有姿态/关节误差和扰动后分离。可以把它作为局部恢复候选，不能作为完整动作恢复能力证明。

下一轮只设计一个独立B1分支：冻结heading300，不扩大当前残差上限，不解冻原Actor，不继续失败model15。原Motion-WM结构不改；首先使用raw一致运动参考和已验证的初始化。新头用显式状态/误差条件化，物理latent是否需要作为独立消融，不把P0预测收益当作必要控制贡献。

应事前固定训练状态、扰动、奖励和完整记录合同，重点是学习扰动后的持续恢复，保护姿态/关节与速度。该片段包含转向和连续深蹲，因此不要命名为纯转向保持任务，也不要把覆盖双脚支撑的结果推广为行走恢复。若要进一步简化任务，应另行预定义真实参考子片段与验收窗口，而不是拼接不协调的固定站姿yaw目标。

先取得教师自身任务及持续恢复收益，再做完整77 raw/WM和独立动作验收。完整保护门保留，任何失败分支停止，不以raw收益替代WM验收，不在本阶段启动PPO、蒸馏或部署。
